[#qualitaetsanforderungen]
= Qualitätsanforderungen
:icons: font

[cols="1,3",options="header"]
|===
| Szenario | Erwartung

| Eine Tafel wird falsch gelesen.
| Mindestens eine Prüfung schlägt fehl; die Abstimmung erscheint als „in Prüfung“ und wird ein Prüffall.

| Das amtliche Ergebnis erscheint nach Wochen.
| Der tägliche Recheck gleicht ab; aus `provisional` wird `verified` oder ein Prüffall.

| Eine Person meldet einen Fehler.
| Der Weg führt über E-Mail oder den Pull Request; die Korrektur ist ein nachvollziehbarer Commit.

| Ein Workflow scheitert.
| Es entsteht ein Issue; bestehende Daten bleiben unverändert.

| Die Seite zieht auf eine eigene Domain um.
| Nur `SITE_URL` und `SITE_BASE` ändern sich.
|===
