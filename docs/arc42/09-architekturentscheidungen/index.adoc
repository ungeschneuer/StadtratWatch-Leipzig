= Architekturentscheidungen
:icons: font

Die folgenden _Architecture Decision Records_ (ADR) dokumentieren Kontext, Alternativen und Konsequenzen der prägenden Entscheidungen. Sie folgen einem schlanken https://adr.github.io/madr/[MADR]-Format. ADR-0001, -0002, -0004 und -0007 stammen aus StadtratWatch Magdeburg und gelten weiter. ADR-0003 (OCR-Pipeline mit Freigabe), -0005 (OParl-Rohdaten auf S3) und -0006 (Web-Assets auf CloudFront) betrafen nur die Magdeburger Pipeline und entfielen mit <<adr-0008,ADR-0008>>; sie stehen in der Git-Historie.
