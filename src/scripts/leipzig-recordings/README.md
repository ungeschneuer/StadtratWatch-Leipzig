# leipzig-recordings

## Purpose

Finds the recordings of the Leipzig city council (Ratsversammlung) in the Mediathek of the city, resolves each HLS
stream and subtitle file, archives the subtitles and writes a machine-readable manifest. It is the first step of the
Leipzig voting pipeline: the voting extraction reads the streams and subtitles listed here.

The city keeps recordings online for roughly a year only, so the script runs daily (see
`.github/workflows/leipzig-recordings.yml`) to catch every recording before it disappears.

## Sources

| Source                                                                             | Used for                                                            |
| ---------------------------------------------------------------------------------- | ------------------------------------------------------------------- |
| OParl `https://www.leipzig.sitzung-online.de/oparl/organizations/gr/2387/meetings` | Council meeting dates and IDs (CC BY 4.0, Stadt Leipzig)            |
| `https://www.leipzig.de/mediathek/video`                                           | Recording pages that are currently listed                           |
| `https://www.leipzig.de/mediathek/video/aufzeichnung-der-ratsversammlung-vom-…`    | Page title (session date) and embedded player parameters            |
| `POST https://start.video-stream-hosting.de/player/playerparameter`                | HLS host and subtitle file; undocumented, used by the player itself |

Recording pages drop off the listing after a while. For meetings without a known recording, the script guesses the page
address from the date (`DDMMYYYY`, `D-monat-YYYY`, `DD-monat-YYYY`), by default only for the last 60 days.

## Usage

From the repository root:

```bash
bun src/scripts/leipzig-recordings/index.ts                # daily run
bun src/scripts/leipzig-recordings/index.ts --backfill     # guess addresses for every meeting of the period
```

| Flag                   | Description                                                                      |
| ---------------------- | -------------------------------------------------------------------------------- |
| `-o, --out-dir`        | Directory of the parliament period. Default: `data/leipzig-8/`.                  |
| `--first-session-date` | First session date of the parliament period. Default: `2024-09-18`.              |
| `--probe-days`         | Guess page addresses only for meetings of the last `<days>` days. Default: `60`. |
| `--backfill`           | Guess page addresses for every meeting since `--first-session-date`.             |
| `-h, --help`           | Show the help text and exit.                                                     |

| Environment variable | Description                                                            |
| -------------------- | ---------------------------------------------------------------------- |
| `SCRAPER_USER_AGENT` | Optional User-Agent; the default names the project and its repository. |

Requests are spaced 0.5 s apart. A run that finds nothing new leaves every file unchanged. If a single page fails, the
other recordings are still written and the script exits with code 1.

## Output

| File                                         | Content                                                 |
| -------------------------------------------- | ------------------------------------------------------- |
| `data/leipzig-8/recordings.json`             | Manifest with sources and one entry per session day     |
| `data/leipzig-8/recordings.csv`              | The same entries as CSV                                 |
| `data/leipzig-8/{date}/subtitles-{date}.vtt` | Archived subtitles (AI-generated by the hoster, German) |

| Field             | Meaning                                                   |
| ----------------- | --------------------------------------------------------- |
| `sessionId`       | Session day, `YYYY-MM-DD`                                 |
| `oparlMeetingId`  | OParl meeting of that day, `null` if OParl has none       |
| `hlsUrl`          | HLS master playlist (360p to 1080p)                       |
| `durationSeconds` | Length of the recording                                   |
| `subtitleUrl`     | Subtitle file at the hoster, `null` if none is published  |
| `subtitleFile`    | Archived copy, kept even after the hoster removes it      |
| `subtitleSha256`  | Hash of the archived subtitles                            |
| `firstSeen`       | Day the recording was first found                         |
| `goneSince`       | Day its page stopped answering, `null` while it is online |
